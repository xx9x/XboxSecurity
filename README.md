  #  Xbox Securing Guide

### Secure your Microsoft/Xbox account the right way.

A comprehensive checklist designed to help reduce the risk of account recovery after purchasing or receiving a Microsoft/Xbox account.

> **Disclaimer:** No purchased Microsoft account is ever **100% secure**. This guide follows current security best practices but **does not guarantee complete account security.**

---

</div>


# 📖 Overview

This guide was created to provide the Xbox community with a **simple**, **organized**, and **effective** security checklist.

Whether you're purchasing, selling, or trading an account, following these steps can greatly reduce your chances of losing access.

---

# 💬 Before Dealing

Never rush into a deal.

Before purchasing an account, verify the seller and the account itself.

### ✅ Verify the seller

- Check onsite reputation
- Review vouches
- Review previous deals
- Verify they actually own the account

### ✅ Request proof

Ask for:

- Screenshot while logged in
- Screen recording (preferred)
- Proof of ownership

### ✅ Use a Trusted Middleman

Whenever possible, always use a trusted middleman to protect both parties.

---

# 🔒 Secure the Account

## Step 1 — Open Microsoft's Security Page

➡️ **Manage Security Information**

https://account.live.com/proofs/manage/additional

---

## Step 2 — Replace EVERYTHING

Replace **every** existing verification method with your own.

Do **not** leave any previous information attached.

Complete the following:

- [ ] Add your own recovery email
- [ ] Add your own phone number
- [ ] Remove previous recovery email(s)
- [ ] Remove previous phone number(s)
- [ ] Remove unknown authentication methods

---

## Step 3 — Enable Security

Complete every item below.

- [ ] Enable Two-Factor Authentication (2FA)
- [ ] Sign Out Everywhere
- [ ] Generate a new App Password
- [ ] Generate a new Recovery Code

---

# ⚙️ Microsoft Account Checklist

---

## 📨 Disable Email Forwarding

Ensure nobody else receives copies of your emails.

➡️ https://outlook.live.com/mail/options/mail/forwarding

- [ ] Email forwarding disabled

---

## 👨‍👩‍👧 Leave Family Groups

Remove the account from any Microsoft Family.

➡️ https://account.microsoft.com/family

- [ ] Left Family Group

---

## 👤 Update Profile Information

Update all personal information.

➡️ https://account.microsoft.com/profile

- [ ] Name
- [ ] Country (if necessary)
- [ ] Personal information

---

## 📧 Primary Alias

Only change the **Primary Alias** if you **do not trust the seller.**

➡️ https://account.live.com/names/manage

- [ ] Reviewed aliases
- [ ] Changed Primary Alias (if necessary)

---

## 🚫 Disable Sign-In for Old Aliases

Prevent old aliases from being used to sign in.

➡️ https://account.live.com/SignInPreferences

- [ ] Disabled unused aliases

---

## 💻 Remove Unknown Devices

Remove every device you do not personally own.

➡️ https://account.microsoft.com/devices

- [ ] Xbox consoles
- [ ] PCs
- [ ] Phones
- [ ] Tablets
- [ ] Unknown devices removed

---

## 🔗 Remove Connected Applications

Review every connected application.

Remove anything unfamiliar.

➡️ https://account.microsoft.com/privacy/app-access

- [ ] Unknown apps removed

---

## 🕒 Review Sign-In Activity

Review all recent logins.

➡️ https://account.live.com/Activity

Confirm every login belongs to you.

- [ ] Login history reviewed

---

# ℹ️ Ask the Seller For

Before releasing payment, ask for:

- [ ] Owner history
- [ ] Console ID
- [ ] Network ID (if applicable)
- [ ] Original password (if available)
- [ ] Purchase history (optional)
- [ ] Confirmation they removed:
  - [ ] Microsoft Authenticator
  - [ ] Passkeys
  - [ ] Recovery methods
  - [ ] Consoles
  - [ ] Trusted devices

---

# 💰 Middleman Recommendation

For expensive accounts, consider having a trusted middleman hold payment for **1–24 hours** after delivery.

This allows time to verify:

- Account remains accessible
- No recovery attempts occur
- All security information has been updated

---

# 🚨 Important

### This guide helps reduce risk.

It **cannot eliminate it.**

A purchased Microsoft account can **always** carry some level of recovery risk.

Never spend more than you're willing to lose.

Always trade responsibly.
